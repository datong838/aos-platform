# 数据健康刷新失败后的当前状态

基线 439f5abe；沿用 data-health-unavailable-plan.md 和当前数据真实性合同。

现场：API 重载后 sources 返回 200；真实源未登记、两个原隧道端口均无监听。既有 SSH 拒绝仍保持，不重试身份、不注册虚构配置。安装 af1992e8 持续 2134 秒、35 次续租、三容器运行，不能据此判业务就绪。

源码缺口：DataHealthPage 刷新失败只设置 err，仍以保留的 data 渲染绿色评分、通过规则及趋势。这会在新观测失败时把历史结果继续作为当前结论，与后端 503 语义不一致。

最小修复文件：apps/web/src/pages/s2/DataHealthPage.tsx。err 存在时不渲染健康摘要，保留错误及手动刷新入口；后续成功清错并展示新结果。不修改共享 hook、数据库、权限或既有正常查询。

测试文件：apps/web/src/pages/s2/DataHealthPage.currentTruth.test.tsx。先复现成功→刷新失败仍显示旧评分，再验证失败不显示旧结论/空数据提示，随后刷新成功使用新评分。保留正常刷新和未知一致率测试。执行页面针对性测试与类型检查，浏览器检查真实健康页。最后证据、清册及接续文档对账提交。
