# 已有材料接入入口

本入口默认仅校验；必须明确--sign才写全新签名制品目录。它不发布Registry、不安装、不启动服务、不修改真实登录；材料公钥匹配不证明正式账号/组织发布权限。

参数：--build（上波外部新候选目录）、--build-receipt、--qualification-receipt、--state（不存在的外部独立目录）、--key-file（已批准既有密钥文件路径，不能位于repo/构建/输出）、--trust-roots-file（已有公钥trust配置路径）、--key-id（已有exactID）。没有材料来源时拒绝，不生成材料；未知签名结果用原intent/result和原资料只读对账，不重新执行。

本次正向仅使用隔离pytest材料，真实材料未接入，原机器真实密钥未读，八工作台仍未恢复。后继真实配置接入/独立发布账号/原Registry发布/安装与当前有效配置逐项验收仍是必需步骤。
