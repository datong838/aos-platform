# 八菜单逐控件可操作性复验

## 范围与方法

- 租户：`org-org/dev-project`。
- 页面：日常任务总控、内容与活动、统一运营、达人邀约、多媒体、经营参谋、价格治理、客户关系。
- 方法：内置浏览器对每个页面重新载入后，逐一点击一级业务动作、内部业务视图、筛选、页签、重新读取和安全预检动作；以 DOM 状态变化、选中态、中文状态提示或明确导航作为可工作证据。
- 安全边界：未手工运行或重放 P01～P12，未调用 Provider，未读取凭据/PII，未写真实业务数据，未执行迁移或发布。

## 逐页结论

| 页面 | 实际点击范围 | 结果 |
| --- | --- | --- |
| 日常任务总控 | 日历视图、下达、重新读取、六位数字同事 | 日历切换、中文输入校验、截止时间更新、六浮层均可见 |
| 内容与活动 | 顶部保存/发布、三主视图、三 canonical 切片、新建活动、生成、保存、重新生成、重读 | 所有动作产生选中态、导航或中文安全预检 |
| 统一运营 | 筛选、新建处理、重读、七业务切片、六安全动作 | 七切片可切换；六动作均有中文预检；读取证据在无输入时明确禁用 |
| 达人邀约 | 导入、新建批次、五主视图、三筛选、五阶段、档案/分析读取、重读 | 状态切换与可信空反馈均可见 |
| 多媒体 | 内容计划导航、新建内容任务、三媒体类型、重读 | 导航、三 tab 选中态、中文预检和截止更新均可见 |
| 经营参谋 | 今日方案、八分析视图、列表/页面重读 | 今日方案进入增长计划；八 tab 逐项选中；重读可见 |
| 价格治理 | 导出、新建策略、三价格视图、刷新 | 中文预检、三 tab 选中态与读取结果可见 |
| 客户关系 | 导入、新建触达、四客户视图、重读 | 中文预检、四 tab 选中态、正式来源 54 与截止更新可见 |

## 复现纠偏

第一轮连续点击曾记录“＋ 新建活动”无 DOM 变化；随后以页面重新载入后的单按钮隔离复验确认其会出现“新建活动预检：当前没有可提交的活动意图，未创建业务记录”。该条为采样假阳性，不据此改代码。媒体“查看内容计划”会导航到内容页，后续媒体按钮均在返回原路由后重新独立验证。

## 裁决

本轮没有发现可重复的静默死控件，不为制造提交修改业务代码。当前八菜单主要控件都能产生业务视图切换、只读刷新、明确导航、中文校验或安全预检；真实数据不足时继续可信空，不注入演示任务。下一循环转向用户已指出的 AIP 模型管理页面，逐页验证其保存、试聊、路由、供应商、容量与运行就绪控件是否仍为静态壳。
