# 行业能力如何成为可组合资产：解析、版本与安装历史

行业解决方案很容易从一个项目开始，也很容易永远停留在一个项目：通用电商模型里混入某平台字段，增长逻辑直接调用某个渠道协议，客户阈值写进代码。第二个客户到来时，团队往往只能复制一份继续改。

要从一次性交付走向产品化，关键不是多建几个目录，而是冻结所有权和组合契约。

## 四层分治

一个通用模型可以拆成四层：

1. 领域核心包：稳定的商品、订单、履约等语义，以及通用指标和数据质量规则；
2. 解决方案包：增长、运营、风控等业务能力，包含 Agent、工作流、策略、界面声明和评测；
3. 平台适配包：某电商或社交平台的协议、字段映射、能力矩阵和数据管道；
4. 实例 Overlay：某个租户的目标、数据引用、密钥引用、调度、阈值和审批配置。

领域核心不能依赖具体平台；平台适配不能包含经营策略；解决方案不能写客户配置；实例只引用精确包版本，不能复制并修改公共包内容。

这四条是可复用性的真正边界。

## Manifest 只是起点

每个资产需要不可变版本、内容哈希、依赖、冲突、能力供需、权限需求、迁移计划、界面或 API 贡献声明，以及验证证据。发布后的同一版本不能修改内容，只能发布新版本。

“验证通过”也不能相信客户端提交的布尔值，而应由 Schema、签名、物料清单、评测和安全证据计算。

## 解析必须是确定性的

依赖解析器不只是找一个“能用的版本”。相同请求和相同 Registry 快照，在任何机器、任何数据库返回顺序下，都必须产生相同结果。

典型规则包括：

- 只从同一个只读快照读取候选；
- required 依赖全部参与，optional 只在顶层明确选择时参与；
- 多个版本范围对候选逐项求同时满足；
- 优先稳定版本，并使用固定排序解决同优先级；
- 全图回溯检查循环、显式冲突、能力提供者冲突和贡献位冲突；
- 设置节点、边、深度、回溯状态和载荷大小预算，超限明确失败。

不能让 wall-clock 超时决定解析结果，因为机器速度会改变最终 lock。时间保护可以存在，但确定性的 step budget 才是主要边界。

## Canonical Lock 冻结了什么

最终 lock 不只保存包版本，还应冻结：规范化请求、Registry 快照哈希、精确内容哈希、签名指纹、依赖边、能力提供者、权限差异、迁移计划、贡献差异和当前安装基线引用。

随后对 canonical JSON 计算 lock hash。时间戳、数据库 ID 和 lock hash 自身不进入哈希载荷；空数组、空对象和 `null` 的语义必须统一，不能有时省略字段、有时写空值。

这样，批准者看到并批准的权限和迁移差异，才与真正安装的内容完全一致。

## 安装历史应当不可变

安装流程可以设计为：

```text
draft → submitted → approved → applied → active → rolled_back
                  └→ rejected
```

每次成功动作插入一个完整的新 revision，历史永不更新。当前指针指向最新 revision，active 指针指向当前生效版本，previous active 指针为回滚保留基线。

并发变更使用强 ETag 和 CAS。审批者批准精确 lock 与差异哈希，请求者不能批准自己的 revision。真正 apply 前还要重新检查依赖版本是否仍可发布、验证证据是否过期、信任根是否仍接受签名。

旧 lock 可以保留审计，但不能穿越资产撤销或信任失效继续激活。

## 回滚不是删除历史

回滚应创建新的终态 revision，并把 active 指针恢复到 previous active；如果不存在上一版本，则回到未安装基线。历史、审批、证据和事件继续保留。

这种设计比“把当前行改回旧值”多占一些存储，却换来更简单的审计、并发语义和事故分析。

## 测试确定性与不变式

除了正常安装，还要测试：

- 同一输入随机打乱候选顺序，lock hash 仍相同；
- 循环依赖、版本交集为空和多个能力提供者；
- 解析资源上限的 `max-1 / max / max+1`；
- 批准后资产被撤销或证据过期；
- 两个请求使用同一 ETag 并发变更；
- 幂等回放遇到后来发生的状态变化；
- 回滚到上一 active 和回到未安装基线；
- 权限、迁移、贡献正文与各自哈希不一致。

可组合交付的本质，是把“这次装了什么、为什么能装、谁批准、产生了哪些差异、如何恢复”变成一个确定且可验证的事实。

至此，这个系列从经营闭环一路走到资产交付底座。多智能体要进入真实业务，模型能力只是起点；证据、契约、治理、连接器、Action 控制和确定性基础设施，才决定系统能否长期演进。
