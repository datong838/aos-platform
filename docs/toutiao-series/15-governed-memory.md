# Agent为什么不能记住所有经验：四层记忆治理

Agent做完一次任务后，最省事的办法是把全部对话和结果写进长期记忆，但这也最容易制造隐患。一次成功可能依赖临时流量、库存、策略版本或人工介入；如果只记住“曾经有效”，偶然结果就会变成未来任务的默认规则。可靠的学习机制必须区分临时状态、案例、稳定事实和可复用方法。

## 一次成功只能成为候选经验

设想一个完全虚构的经营场景：某次任务发现，一组低活跃用户对“使用场景讲解”内容反应较好。内容 Agent 调整表达，关系运营 Agent 选择触达时间，导购 Agent 补充选购建议，最终结果符合预期。

团队可以记录这次经历，却不能马上形成“低活跃用户都应优先接收场景型内容”的永久规则。这个结论忽略了品类、渠道、触达频率、价格变化、观察窗口，以及是否出现退订或投诉等条件。

任务结束后，系统首先应生成候选经验，并保留五类证据：

• 当时要解决的问题
• 适用的人群、渠道和时间条件
• 实际执行的方案版本
• 主指标与护栏指标的变化
• 失败、例外和无法解释的因素

没有适用条件的经验，几乎必然会被错误迁移。

## 四层记忆分别解决什么问题

第一层是工作记忆，只服务当前任务。它保存计划、待办、临时分析和交接状态，并带有明确任务边界与过期时间。任务结束后应清理或归档，不能让一次临时约束长期影响后续推荐。

第二层是情景记忆，保存“在什么条件下做了什么，结果如何”。它更像可检索案例，而不是必须执行的规则。再次遇到相似问题时，系统可以召回案例，同时展示本次与历史条件的差异。

第三层是语义记忆，保存经过确认的稳定事实，例如授权商品属性、业务术语、政策边界和指标定义。它必须带来源、版本、生效范围和失效机制。

第四层是程序记忆，保存一类任务的可复用做法，例如先检查数据就绪，再识别异常，随后生成方案并进入审批。它会直接影响未来行为，因此风险最高，必须经过多案例验证、人工审查和回归测试。

## 经验怎样晋升为长期记忆

从任务结果到长期记忆，中间需要一条治理流水线：

任务结束
→ 提取条件、动作、结果和护栏
→ 脱敏、去重、冲突检测、适用范围标注
→ 跨案例比较与反例检索
→ 离线评估与全局回归测试
→ 人工或治理流程批准
→ 版本化发布、监测、到期或撤销

最容易被忽略的是反例检索。系统不能只问“哪些案例支持这条经验”，还要主动寻找“相似条件下，它在哪些时候失败”。如果只有正例，所谓规律可能只是幸存者偏差。

评估也不能只看模型回答是否流畅。更实用的指标包括错误召回率、护栏违规率、人工改写率、建议采纳后的结果变化，以及面对新场景时能否准确回答“不适用”或“证据不足”。

## 每个角色应有自己的专业记忆

多 Agent 团队不应共享一个无限扩张的公共记忆池。

内容 Agent 可以积累不同表达方式的适用条件，却不需要读取客服处理个案时的完整对话；导购 Agent 可以使用经过确认的商品知识，却不应继承关系运营角色的联系人工作清单；活动 Agent 需要预算和机制规则，但不需要读取所有用户明细。

团队适合共享的是经过治理的公共事实、政策、术语和交接契约，而不是彼此的原始工作记忆。每次读取仍要检查角色权限、任务目的、数据范围和记忆版本。

这既保护隐私，也避免角色污染。内容角色若长期吸收零散售后个案，可能为回避极少数问题而让所有表达变得含糊；导购角色若读到未批准的活动草案，可能提前承诺尚不存在的权益。

## 三类记忆失败最值得警惕

第一类是把结果当规律。系统看到一次成功就生成通用规则，忽略当时的适用条件和人工介入。对策是先进入情景记忆，再通过跨案例评估决定是否晋升。

第二类是把摘要当脱敏。原始对话即使被模型压缩，仍可能保留身份线索或敏感事实。对策是使用专门的去标识和用途审查，而不是依赖自然语言改写。

第三类是遇到冲突仍强行选择答案。旧方法可能在新渠道失效，两条经验也可能分别适用于不同人群。系统不应简单选择最新或出现次数最多的一条，而要比较来源、范围、版本和当前条件；无法消解时，应降低置信度并转人工。

另一个长期风险是记忆只增不减。商品、政策、渠道和用户偏好都会变化，没有到期与撤销路径的知识库，只会越来越自信地使用过时结论。

## 可直接执行的记忆治理清单

设计 Agent 记忆系统时，可以逐项检查：

• 工作记忆是否绑定任务并设置到期时间
• 情景记忆是否保留条件、动作、结果、护栏和例外
• 语义事实是否具有来源、版本和生效范围
• 程序记忆是否经过跨案例评估与人工批准
• 候选经验是否完成脱敏、去重和冲突检测
• 评估是否主动检索反例，而不只统计正例
• 不同角色是否拥有独立的专业记忆边界
• 共享记忆是否只包含经过治理的公共知识
• 冲突无法消解时，系统是否允许回答“不知道”
• 每条长期记忆是否能够过期、撤销和回滚

数字团队“越做越聪明”，不应表现为越来越敢自动行动，而应表现为更少的无效建议、更清楚的适用边界、更稳定的护栏，以及更准确的人工升级时机。记忆提供证据与方法，但不能自动扩大权限。
