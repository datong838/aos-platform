## 1. 这是什么？

**CBEC-OPS** 是一套专为跨境电商卖家打造的 AI 助手知识库。安装后，你的 AI 助手（Claude）就拥有了资深跨境电商运营的全部知识体系——从选品调研到写 Listing，从谈供应商到管库存，从开广告到算利润，从应对封号到备战黑五。

**你不需要记任何命令。** 用自然语言提问就行：

> "帮我分析东南亚市场卖蓝牙耳机的可行性"
>
> "给这个产品算一下到手成本，看能不能做"
>
> "帮我写一个 Amazon 的五点描述"

AI 会自动识别你的需求，调用对应的专业知识，给出结构化的分析和建议。

### 核心能力

- **16个专业技能（Skills）** 覆盖跨境电商完整生命周期
- **39份参考数据文件** 包含平台费率、打分卡、谈判脚本、合规政策等
- **多平台支持** Amazon、Shopee、TikTok Shop、Lazada、Walmart 等主流平台
- **中英文对话** Skills 内部用英文编写（AI 处理效率最高），但你可以用中文提问，AI 会用中文回答

## 2. 安装与配置

### 前置条件

- 已安装 [Claude Code](https://docs.anthropic.com/en/docs/claude-code)（命令行版本）
- Node.js 18+ 环境

### 安装方式

**方式一：本地安装（推荐）**

```bash
# 克隆项目
git clone https://github.com/your-repo/cbec-ops.git

# 在 Claude Code 中添加为插件
claude plugin add /path/to/cbec-ops
```

**方式二：直接指定路径**

如果你已经下载了项目，直接在 Claude Code 配置中添加插件路径即可。

### 验证安装

打开 Claude Code，输入以下问题：

```
我想做跨境电商，从哪里开始？
```

如果 AI 开始系统性地引导你进行市场调研和选品分析，说明安装成功。

## 3. 快速开始（5分钟上手）

### 你的第一个对话

安装完成后，直接用自然语言和 AI 对话即可。以下是三个经典场景，复制提问就能体验：

### 场景一：市场调研 + 选品

```
帮我分析美国市场卖瑜伽垫的可行性。
我预算 10 万人民币，新手卖家，走 Amazon FBA。
```

AI 会：
1. 用 **market-research** skill 评估美国瑜伽垫市场（需求、竞争、物流、合规）
2. 用 **product-selection** skill 对"瑜伽垫"进行 30 项验证打分
3. 给出明确的"建议进入/不建议进入"结论

### 场景二：供应商 + 定价

```
我要在1688上找瑜伽垫供应商，预算5万，目标是 Amazon US FBA。
帮我规划找供应商的流程，以及算一下到手成本和定价。
```

AI 会：
1. 用 **supplier-sourcing** skill 规划 1688 搜索策略、样品验证流程
2. 用 **pricing-strategy** skill 计算完整到手成本（产品+运费+关税+FBA费+广告预留+退货预留）
3. 给出建议售价和预期利润率

### 场景三：写 Listing

```
帮我写一个 Amazon US 的瑜伽垫 listing。
产品特点：TPE材质，6mm厚，防滑纹理，附带背带，售价 $29.99。
目标客户：家庭健身的女性，25-45岁。
```

AI 会：
1. 用 **product-listing** skill 生成完整 Listing（标题、五点描述、产品描述、后台关键词）
2. 融入关键词 SEO 策略
3. 标注需要优化的图片方向

## 4. 完整业务流程（6阶段路线图）

跨境电商是一个完整的业务链条。CBEC-OPS 将整个链条分为 6 个阶段，每个阶段有对应的 Skills 支持：

```
阶段 1          阶段 2          阶段 3              阶段 4              阶段 5          阶段 6
发现            采购            上架                增长                优化            保护与扩展
DISCOVER        SOURCE          LAUNCH              GROW                OPTIMIZE        PROTECT & EXPAND
   |               |               |                   |                   |               |
选市场          找供应商        写Listing           开广告              看数据          守合规
选产品          算成本          备库存              做客服              算账            防风险
                定价格          发物流              建品牌                              备大促
                                                                                      拓平台
```

### Phase 1: 发现（DISCOVER）

| 要素 | 详情 |
|------|------|
| **目标** | 确定卖什么、卖到哪里 |
| **涉及 Skills** | `market-research` + `product-selection` |
| **关键决策** | 市场评分 ≥ 3.5/5 → 产品打分 ≥ 21/30 → 进入采购 |
| **铁律** | 不因市场大而进入，因有可衡量优势才进入。产品不过 21 分不下单 |

**进入下一阶段的条件：** 至少 1 个产品通过 30 项验证打分卡（≥ 21 分）

### Phase 2: 采购（SOURCE）

| 要素 | 详情 |
|------|------|
| **目标** | 找到靠谱供应商，确认产品可盈利 |
| **涉及 Skills** | `supplier-sourcing` + `pricing-strategy` |
| **关键决策** | 样品合格 → 到手成本可控 → 毛利率 ≥ 30% → 下生产订单 |
| **铁律** | 未验样品不下大货。不算全部到手成本就定价 = 给平台捐钱 |

**进入下一阶段的条件：** 样品通过验收 + 到手成本计算完毕 + 确认可盈利

### Phase 3: 上架（LAUNCH）

| 要素 | 详情 |
|------|------|
| **目标** | 产品上线并可被顾客搜索到 |
| **涉及 Skills** | `product-listing` + `inventory-management` + `order-fulfillment` |
| **关键决策** | Listing 质量审核 → 首批库存数量 → 物流方式选择 |
| **铁律** | SEO 和转化必须同时优化。库存目标是不断货的最小库存 |

**进入下一阶段的条件：** Listing 上线 + 库存到达仓库 + 订单可正常履约

### Phase 4: 增长（GROW）

| 要素 | 详情 |
|------|------|
| **目标** | 获取流量，建立评价，打造品牌 |
| **涉及 Skills** | `advertising-marketing` + `customer-service` + `brand-building` |
| **关键决策** | 广告预算分配 → 评价速度策略 → 是否投入品牌建设 |
| **铁律** | 烂 Listing 花更多广告只是烧钱更快。品牌建设需确认 PMF 后再投入 |

**进入下一阶段的条件：** 日均订单稳定 + 评价数 ≥ 30 + ACOS 可控

### Phase 5: 优化（OPTIMIZE）

| 要素 | 详情 |
|------|------|
| **目标** | 用数据驱动决策，确保真正盈利 |
| **涉及 Skills** | `data-analytics` + `financial-management` |
| **关键决策** | 哪些 SKU 砍掉 → 广告预算重新分配 → 现金流是否健康 |
| **铁律** | 衡量重要的，不是容易的。营收是虚荣，利润是理智，现金流是现实 |

**进入下一阶段的条件：** 每月 P&L 清晰 + 知道每个 SKU 的真实利润

### Phase 6: 保护与扩展（PROTECT & EXPAND）

| 要素 | 详情 |
|------|------|
| **目标** | 守住现有业务，有序拓展 |
| **涉及 Skills** | `platform-compliance` + `risk-management` + `seasonal-planning` + `multi-platform-expansion` |
| **关键决策** | 合规自查 → 风险备案 → 大促备战（T-90天）→ 是否扩展新平台 |
| **铁律** | 没有捷径值得冒封号风险。希望不是策略。大促在活动前 90 天决定 |

**这个阶段是持续进行的**——在任何阶段都应该关注合规和风控。

## 5. 16个Skills速查卡

### Phase 1: 发现

#### market-research — 市场调研

| 项目 | 内容 |
|------|------|
| **一句话** | 评估和排名目标市场，决定卖到哪里 |
| **触发提问** | "我应该卖到哪个国家？" / "分析一下东南亚市场" / "美国和欧洲哪个市场更适合新手？" |
| **铁律** | 不因市场大而进入，因有可衡量优势才进入 |
| **参考文件** | `market-profiles.md`（各国市场画像）、`platform-landscape.md`（平台-市场适配矩阵） |

#### product-selection — 选品

| 项目 | 内容 |
|------|------|
| **一句话** | 用数据驱动的打分卡筛选和验证产品 |
| **触发提问** | "帮我找个产品来卖" / "瑜伽垫值得做吗？" / "怎么判断一个产品有没有机会？" |
| **铁律** | 产品必须通过 30 项验证打分卡 ≥ 21 分才能下单 |
| **参考文件** | `trend-sources.md`（趋势发现渠道）、`validation-checklist.md`（30项验证打分卡） |

### Phase 2: 采购

#### supplier-sourcing — 找供应商

| 项目 | 内容 |
|------|------|
| **一句话** | 在 1688/工厂找供应商，谈判、验样、建立供应体系 |
| **触发提问** | "帮我在1688找供应商" / "怎么验厂？" / "MOQ太高怎么谈？" |
| **铁律** | 未验样品不下大货，单一供应商不超 60% 产能 |
| **参考文件** | `1688-workflow.md`（1688搜索流程）、`factory-audit.md`（验厂清单）、`negotiation-playbook.md`（谈判脚本） |

#### pricing-strategy — 定价策略

| 项目 | 内容 |

| **触发提问** | "帮我算到手成本" / "这个产品该定多少钱？" / "做促销还能赚钱吗？" |
| **铁律** | 不算全部到手成本就定价 = 给平台捐钱 |
| **参考文件** | `cost-calculator.md`（成本计算公式）、`platform-fees.md`（各平台费率表） |

### Phase 3: 上架

#### product-listing — 产品刊登

| 项目 | 内容 |

| 项目 | 内容 |

## 6. 常见提问方式（Prompt 指南）

### 按场景分类

#### 场景：我是新手，不知道从哪开始

```
我是跨境电商新手，预算 X 万，想做 Amazon，帮我规划从选品到上架的完整流程。
```

```
帮我对比一下做 Amazon US 和 Shopee 东南亚，哪个更适合新手？
```

```
我有一个产品想法：[产品名]。帮我做一个完整的可行性分析。
```

#### 场景：我在选品阶段

```
帮我用 30 项打分卡评估"[产品名]"这个品类。
```

```
[产品名]在 Amazon US 的竞争程度如何？头部卖家的 review 数和价格带是多少？
```

```
帮我分析 [品类] 的趋势，现在入场还来得及吗？
```

#### 场景：我要优化 Listing

```
帮我重写这个 Listing 的标题和五点描述（附上当前Listing内容）。
目标关键词：[关键词1], [关键词2], [关键词3]
```

```
帮我做一个 Shopee [产品名] 的 Listing，目标市场是马来西亚。
```

```
我的转化率只有 5%，帮我诊断 Listing 问题在哪里。
```

#### 场景：我被封号 / 收到警告了

```
我的 Amazon 账号因为 [原因] 被封了，帮我写一封申诉信（Plan of Action）。
```

```
Shopee 扣了我 3 分，原因是 [原因]，我该怎么办？
```

```
帮我做一次全面的合规自查，看看有没有违规风险。
```

#### 场景：大促要来了

```
黑五还有 90 天，帮我制定备战计划。
我有 [N] 个 SKU，广告预算 [X] 美金。
```

```
双11快到了，帮我算一下 Shopee 需要备多少货。
```

```
春节工厂放假，帮我规划 CNY 期间的库存应对方案。
```

### 进阶用法：组合多个 Skills

你可以在一次对话中串联多个阶段：

```
从零开始做一个产品：
1. 帮我调研日本市场卖保温杯的机会
2. 如果可行，帮我找1688供应商并算成本
3. 最后帮我写一个 Amazon JP 的 Listing

一条龙搞定。
```

你也可以让 AI 做对比分析：

```

- 费率差多少？
- 广告策略有什么区别？
```

## 8. 常见问题（FAQ）

### Q: AI 给的信息准确吗？

AI 的知识来源于训练数据和这套 Skills 中的参考文件。参考文件中的费率表、政策条款等会随平台更新而变化。建议：

- **费率和政策：** 以平台官方后台显示为准，AI 的数据作为参考基准
- **市场判断：** AI 的分析框架是可靠的，但具体数据（如 BSR、竞品价格）建议用 Jungle Scout、Helium 10 等工具验证
- **Listing 文案：** AI 生成的文案质量高，但上架前建议做人工审核和 A/B 测试

### Q: AI 能帮我操作卖家后台吗？

不能。CBEC-OPS 提供的是**决策建议和内容生成**，不会自动操作任何平台后台。你需要自己登录卖家中心执行操作（创建 Listing、设置广告、发货等）。

### Q: 支持用什么语言写 Listing？

AI 可以帮你生成以下语言的 Listing 内容：
- **英语**（Amazon US/UK, Shopee SG/PH/MY, TikTok Shop US/UK, Walmart, eBay）
- **中文**（Shopee TW, 内贸参考）
- **日语**（Amazon JP）
- **泰语/越南语/印尼语/马来语**（Shopee/Lazada 东南亚市场）
- **西班牙语/葡萄牙语**（Mercado Libre, Amazon MX/ES）
- **德语/法语/意大利语**（Amazon EU）

AI 会根据你指定的目标市场自动使用对应语言。

### Q: 数据从哪里来？

- **市场画像和平台数据：** 内置在 Skills 的参考文件中
- **实时数据：** AI 会建议你使用第三方工具获取（如 Jungle Scout、Helium 10、Keepa、Google Trends、1688 热搜）
- **竞品分析：** AI 可以教你分析方法，但具体数据需要你从平台获取

### Q: 怎么更新 Skills？

```bash
# 如果通过 git 安装
cd /path/to/cbec-ops && git pull

# 重新加载插件
claude plugin reload cbec-ops
```

### Q: 一个 Skill 能用多长时间？

每个 Skill 没有使用时限。你可以反复使用同一个 Skill 来处理不同产品、不同市场的问题。Skills 之间也可以自由组合。

### Q: 我的数据安全吗？

CBEC-OPS 是纯本地插件，不会上传任何数据到外部服务器。你和 AI 的对话数据遵循 Claude Code 的隐私政策。

## 9. 术语表

### 平台与模式

| 缩写 | 英文全称 | 中文 | 解释 |
|------|---------|------|------|
| **FBA** | Fulfillment by Amazon | 亚马逊物流 | 亚马逊代发货服务，卖家将货物发到亚马逊仓库，由亚马逊完成拣货、打包、发货和客服 |
| **FBM** | Fulfillment by Merchant | 卖家自发货 | 卖家自己（或通过3PL）处理发货 |
| **FBT** | Fulfillment by TikTok | TikTok物流 | TikTok Shop的代发货服务 |
| **FBL** | Fulfillment by Lazada | Lazada物流 | Lazada的代发货服务 |
| **SLS** | Shopee Logistics Service | Shopee物流服务 | Shopee的物流解决方案 |
| **3PL** | Third-Party Logistics | 第三方物流 | 外包的仓储和配送服务商 |
| **MCF** | Multi-Channel Fulfillment | 多渠道配送 | 用Amazon仓库为其他平台的订单发货 |
| **MOQ** | Minimum Order Quantity | 最小起订量 | 供应商要求的最低下单数量 |
| **SKU** | Stock Keeping Unit | 库存单位 | 每个独特商品变体的编号 |
| **ASIN** | Amazon Standard Identification Number | 亚马逊标准识别号 | Amazon上每个商品的唯一编号 |
| **FNSKU** | Fulfillment Network SKU | 配送网络SKU | Amazon FBA仓库中每个卖家商品的唯一标签码 |

### 广告与营销

| 缩写 | 英文全称 | 中文 | 解释 |
|------|---------|------|------|
| **PPC** | Pay Per Click | 按点击付费 | 每次广告被点击时付费的广告模式 |
| **CPC** | Cost Per Click | 每次点击费用 | 每次广告点击的实际花费金额 |
| **ACOS** | Advertising Cost of Sales | 广告销售成本比 | 广告花费 / 广告带来的销售额 * 100%。越低越好，一般目标 < 30% |
| **ROAS** | Return on Ad Spend | 广告支出回报率 | 广告带来的销售额 / 广告花费。ACOS 的倒数，越高越好 |
| **TACoS** | Total Advertising Cost of Sales | 总广告销售成本比 | 广告花费 / 总销售额（含自然订单）。衡量广告对整体业务的影响 |
| **DSP** | Demand-Side Platform | 需求方平台 | Amazon的程序化广告平台，可在Amazon内外投放展示广告 |
| **KOL** | Key Opinion Leader | 关键意见领袖 | 网红/达人，可付费合作推广产品 |

### 运营指标

| 缩写 | 英文全称 | 中文 | 解释 |
|------|---------|------|------|
| **BSR** | Best Sellers Rank | 畅销排名 | Amazon上商品在其类目中的销量排名，数字越小卖得越好 |
| **CVR** | Conversion Rate | 转化率 | 下单人数 / 访问人数 * 100%。衡量Listing把流量变成订单的能力 |
| **IPI** | Inventory Performance Index | 库存绩效指标 | Amazon的库存健康评分（0-1000），低于400会限制补货 |
| **LTSF** | Long-Term Storage Fee | 长期仓储费 | Amazon对存放超过271天的库存收取的额外费用 |
| **EOQ** | Economic Order Quantity | 经济订购量 | 使总库存成本（下单成本+持有成本）最小化的最优订购数量 |
| **ROP** | Reorder Point | 补货点 | 库存下降到这个数量时必须下单补货，否则会断货 |
| **PMF** | Product-Market Fit | 产品市场匹配 | 产品满足市场需求的程度，是投入品牌建设的前提 |

### 财务与税务

| 缩写 | 英文全称 | 中文 | 解释 |
|------|---------|------|------|
| **P&L** | Profit and Loss | 损益表 | 记录一定时期内收入和支出的财务报表 |
| **VAT** | Value Added Tax | 增值税 | 欧盟等地区对商品流转征收的税，跨境电商需要注册和申报 |
| **GST** | Goods and Services Tax | 商品及服务税 | 新加坡、澳大利亚等国家的消费税 |
| **HS Code** | Harmonized System Code | 海关编码 | 国际统一的商品分类编码，用于报关和计算关税 |
| **COD** | Cash on Delivery | 货到付款 | 东南亚市场常见的支付方式，买家收货时付款 |

### 品牌与合规

| 缩写 | 英文全称 | 中文 | 解释 |
|------|---------|------|------|
| **IP** | Intellectual Property | 知识产权 | 包括商标、专利、版权等，是品牌保护的核心 |
| **A-to-Z** | A-to-Z Guarantee Claim | A到Z索赔 | Amazon买家保障机制，买家可直接向Amazon投诉卖家 |
| **TOS** | Terms of Service | 服务条款 | 平台的使用规则，违反可能导致封号 |
| **POA** | Plan of Action | 行动计划 | 向Amazon提交的申诉信，说明问题根因和改进措施 |
