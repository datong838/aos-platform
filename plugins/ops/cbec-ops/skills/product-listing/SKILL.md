# Product Listing Optimization

Create high-converting, search-optimized product listings across e-commerce platforms.
This skill covers the full listing lifecycle: keyword research, copywriting, image
strategy, variation setup, and ongoing optimization.

## Core Principle

A listing's job is to be found AND to convert. SEO without conversion is traffic waste.
Conversion without discoverability is a hidden gem. Both must be optimized simultaneously.

Every element of a listing serves dual duty:

- **Discoverability**: title, backend keywords, category placement, and attributes feed
  the search algorithm so shoppers can find the product.
- **Conversion**: images, bullet points, descriptions, reviews, and pricing persuade the
  shopper to buy once they land on the page.

The highest-performing listings treat these as one integrated system, not separate tasks.

## Universal Listing Framework

Regardless of platform, a complete product listing contains six pillars. Optimize them
in this priority order:

### 1. Title

The title is the single most important SEO element. It must contain the primary keyword
while remaining readable to humans.

**Structure**: Brand + Core Keyword + Key Feature + Product Type + Spec/Size + Differentiator

**Rules**:
- Lead with the highest-volume keyword phrase.
- Include the brand name (required on most platforms).
- Avoid keyword stuffing; one occurrence of each important keyword is enough.
- Do not use ALL CAPS or excessive punctuation.
- Respect platform character limits (see Platform Router).

### 2. Images

Images are the primary conversion driver. Shoppers decide within seconds based on the
main image alone.

**Minimum viable set** (aim for 7-9 images):

| Slot | Purpose | Notes |
|------|---------|-------|
| 1 | Main / hero | White or clean background, product fills 85%+ of frame |
| 2 | Lifestyle / in-use | Show the product in its natural context |
| 3 | Scale / dimensions | Include a reference object or measurements |
| 4 | Key feature close-up | Highlight the #1 differentiating feature |
| 5 | Infographic | Callout 3-5 benefits with text overlays |
| 6 | Package contents | Everything the buyer receives |
| 7 | Comparison / before-after | Show advantage over alternatives |
| 8-9 | Additional angles or use cases | Fill gaps in the visual story |

See [Image Requirements](#image-requirements) for technical specs.

### 3. Bullet Points / Key Features

Bullet points bridge discovery and conversion. Each bullet should integrate a keyword
naturally while communicating a clear benefit.

**Formula per bullet**: Feature + Benefit + Proof/Detail

```
Example:
[KEYWORD-RICH FEATURE] - Explain the tangible benefit to the buyer.
Include a specific detail, measurement, or use case that builds credibility.
```

**Guidelines**:
- 5 bullets for Amazon; 5-8 for other platforms (adapt to platform norms).
- Lead each bullet with the most important keyword or benefit.
- Use sentence case with a dash or colon separator.
- Keep each bullet under 250 characters for mobile readability.
- Address a distinct concern per bullet: quality, ease of use, durability, value, compatibility.

### 4. Product Description

The description is a secondary conversion element. On platforms with rich content
(Amazon A+ Content, Shopee enhanced description), use it for brand storytelling and
visual reinforcement.

**Frameworks** (choose one per listing):
- **Problem-Agitate-Solve (PAS)**: State the problem, amplify the pain, present the product as the solution.
- **Feature-Advantage-Benefit (FAB)**: List a feature, explain its advantage, connect to a buyer benefit.

**Rules**:
- Break text into short paragraphs (2-3 sentences each).
- Use subheadings if the platform supports them.
- Repeat primary keyword 2-3 times naturally.
- Include a clear call to action.
- Never copy-paste the bullet points verbatim.

### 5. Backend Keywords / Search Terms

Backend fields are invisible to shoppers but critical for search coverage. Use them to
capture synonyms, alternate spellings, and long-tail phrases not already in the title
or bullets.

**Rules**:
- Do not repeat words already in the title.
- Use lowercase, space-separated terms (no commas on Amazon).
- Include common misspellings, abbreviations, and foreign-language terms where relevant.
- Never include competitor brand names, ASINs, or false claims.
- Stay within the byte limit (see Platform Router).

### 6. Variations

Variations (color, size, bundle quantity) affect both conversion and search ranking.

**When to group as variations**:
- Products share the same core function and differ only in size, color, or quantity.
- Grouping consolidates reviews and improves ranking.

**When to list separately**:
- Products serve different use cases or target different keywords.
- Price differences are large enough to warrant separate positioning.

## Keyword Research Workflow

### Step 1: Seed Keywords

Gather initial keyword ideas from:
- Autocomplete suggestions on the target platform's search bar.
- Competitor listing titles (top 10 results for your product type).
- Customer review language ("I bought this for...", "works great as a...").
- Category browse tree labels.

### Step 2: Expand

Broaden the seed list using:
- Platform-specific keyword tools (Amazon Brand Analytics, Shopee Keyword Ads tool).
- Third-party tools (Helium 10, Jungle Scout, Merchant Words for Amazon; similar tools for other platforms).
- Related search suggestions and "customers also searched for" data.
- Long-tail variations: add modifiers like "for [use case]", "with [feature]", "[material] [product]".

### Step 3: Prioritize

Rank keywords by a composite score:

| Factor | Weight | How to Assess |
|--------|--------|---------------|
| Search volume | High | Platform keyword tool or third-party estimate |
| Relevance | Critical | Does this keyword accurately describe the product? |
| Competition | Medium | Number of results; quality of page-1 listings |
| Purchase intent | High | Transactional phrases ("buy", "best", specific specs) rank higher |
| Current ranking | Low | If already ranking, maintain; if not, evaluate effort |

**Output**: A ranked keyword list with primary keyword (title lead), secondary keywords
(title + bullets), and tertiary keywords (backend / description).

## Image Requirements

### Universal Best Practices

- **Resolution**: minimum 1000 x 1000 px; recommended 2000 x 2000 px for zoom.
- **Format**: JPEG or PNG; JPEG preferred for photos, PNG for graphics with text.
- **File size**: under 10 MB per image (most platforms cap at 5 MB).
- **Main image**: product only, white or clean background, no text/badges/watermarks.
- **Lifestyle images**: well-lit, in-context, show the product in use by the target demographic.
- **Infographics**: limit text overlays to 3-5 short callouts; use readable font sizes.
- **Video**: include at least one product video (15-60 seconds) where supported.

### Platform-Specific Image Specs

| Platform | Aspect Ratio | Min Resolution | Max Images | Video Support |
|----------|-------------|----------------|------------|---------------|
| Amazon | 1:1 | 1000 x 1000 | 9 (7 + 1 video) | Yes |
| Shopee | 1:1 or 2:3 | 800 x 800 | 9 | Yes (priority) |
| TikTok Shop | 1:1 | 600 x 600 | 9 | Yes (critical) |
| Lazada | 1:1 | 800 x 800 | 8 | Yes |
| eBay | 1:1 | 500 x 500 | 12 | Yes |

## Listing Quality Audit Checklist

Run this 10-point check before publishing any listing:

- [ ] **1. Primary keyword in title** -- The highest-volume relevant keyword appears
  in the first 80 characters of the title.
- [ ] **2. All image slots filled** -- At least 7 images uploaded; main image meets
  platform white-background requirements.
- [ ] **3. Bullet points complete** -- All available bullet slots used; each follows
  the Feature + Benefit + Detail formula.
- [ ] **4. Description is unique** -- Not copy-pasted from bullets; uses a structured
  framework (PAS or FAB).
- [ ] **5. Backend keywords populated** -- No wasted space; no repeated title words;
  within byte limit.
- [ ] **6. Category is accurate** -- Product is in the most specific applicable category;
  browse node verified.
- [ ] **7. Attributes filled** -- All relevant product attributes (material, dimensions,
  weight, color) are populated.
- [ ] **8. Pricing is set** -- Price aligns with pricing strategy; compare to top 5
  competitors.
- [ ] **9. Variations configured** -- If applicable, parent-child relationships are
  correct; each child has unique images.
- [ ] **10. Mobile preview checked** -- Title, images, and bullets render correctly on
  mobile viewport; no truncation surprises.

## Red Flags and Common Mistakes

**Keyword Mistakes**:
- Stuffing the title with repetitive keywords (hurts readability and can trigger penalties).
- Using irrelevant high-volume keywords (drives unqualified traffic, increases returns).
- Ignoring long-tail keywords (missing purchase-intent traffic).
- Duplicating title keywords in backend search terms (wastes backend space).

**Image Mistakes**:
- Using only product-on-white images without lifestyle or infographic shots.
- Low-resolution images that appear blurry on desktop zoom.
- Text-heavy infographics unreadable on mobile.
- Watermarks or promotional badges on the main image.

**Copy Mistakes**:
- Feature-only bullets with no benefit connection ("Made of stainless steel" vs "Made of stainless steel so it resists rust and lasts for years").
- Copy-pasting the manufacturer description without optimization.
- Writing for the brand, not for the shopper.
- Ignoring mobile truncation (first 3 bullets and 80 title characters matter most).

**Structural Mistakes**:
- Wrong category selection (suppresses search visibility).
- Missing product attributes (filters exclude the listing).
- Poor variation strategy (splitting when merging would consolidate reviews, or merging unrelated products).
- Not localizing listings for different markets (direct translation without cultural adaptation).
