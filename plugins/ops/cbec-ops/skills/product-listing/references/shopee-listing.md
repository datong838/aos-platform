## Title Optimization

Shopee titles are the primary search ranking factor. The algorithm weights keywords
by position, with the first words carrying the most influence.

### Structure

```
[Primary Keyword] [Secondary Keyword] [Product Type] [Key Feature] [Spec/Size] [Brand]
```

Note: Unlike Amazon, brand name goes at the end on Shopee (unless the brand is itself
a search keyword). Front-load the highest-volume keyword.

### Character Limits by Market

| Market | Max Characters | Recommended |
|--------|---------------|-------------|
| Singapore (SG) | 120 | 80-100 |
| Malaysia (MY) | 120 | 80-100 |
| Thailand (TH) | 120 | 80-100 |
| Philippines (PH) | 120 | 80-100 |
| Indonesia (ID) | 120 | 80-100 |
| Vietnam (VN) | 120 | 80-100 |
| Taiwan (TW) | 120 | 80-100 |

### Title Rules

- **Keyword-front-load**: Place the primary keyword in the first 40 characters.
- **No ALL CAPS**: Shopee may flag or suppress listings with excessive capitalization.
- **No special characters**: Avoid excessive symbols like "!!!", "***", or "~~~".
- **No promotional text**: Do not include "FREE SHIPPING", "SALE", "CHEAPEST" in the title.
- **Use local language where appropriate**: For TH, ID, VN markets, mixing local
  language keywords with English product terms is common and effective.
- **Include specs**: Size, quantity, weight, and material help with long-tail searches.
- **Avoid keyword stuffing**: Do not repeat the same word more than twice.

### Title Examples

**Electronics (SG/MY)**:
```
Wireless Bluetooth Earbuds TWS 5.3 Noise Cancelling Earphone Sport Waterproof IPX5 with Charging Case
```

**Fashion (ID)**:
```
Tas Selempang Wanita Korean Style Sling Bag Kulit PU Crossbody Bag Import
```

**Home (TH)**:
```
ชั้นวางของ ชั้นวางในครัว สแตนเลส 3 ชั้น Kitchen Rack Stainless Steel Storage Shelf
```

## Description Format

Shopee descriptions are visible to buyers and play a role in conversion. Shopee's
audience expects structured, visually scannable descriptions.

### Formatting Style

Shopee supports plain text with line breaks. Emoji usage is common and expected on the
platform (unlike Amazon). Structure descriptions with clear sections.

### Recommended Description Template

```
[Product Name] [Key Selling Point]

[Emoji] KEY FEATURES:
[Emoji] Feature 1 - Benefit explanation
[Emoji] Feature 2 - Benefit explanation
[Emoji] Feature 3 - Benefit explanation
[Emoji] Feature 4 - Benefit explanation
[Emoji] Feature 5 - Benefit explanation

[Emoji] SPECIFICATIONS:
- Material: [material]
- Size: [dimensions]
- Weight: [weight]
- Color: [available colors]
- Package includes: [list contents]

[Emoji] HOW TO USE:
1. Step one
2. Step two
3. Step three

[Emoji] SHIPPING INFO:
- Ships within [X] days
- Estimated delivery: [X-Y] days

[Emoji] NOTE:
- Due to lighting and screen differences, actual color may vary slightly.
- Please check size chart before ordering.
- If you have any questions, chat with us!
```

### Description Best Practices

- **Length**: 500-1500 characters is the sweet spot. Too short looks low-effort; too
  long is not read.
- **Emoji usage**: Use relevant emojis as bullet markers and section headers. Common
  choices include icons for stars, checkmarks, packages, trucks, and warning signs.
  Keep it professional; 1-2 emojis per line maximum.
- **Keyword integration**: Include primary and secondary keywords naturally within the
  description. The description is indexed for search.
- **Address objections**: Include size charts, material details, care instructions,
  and shipping notes to reduce pre-purchase questions.
- **Social proof**: Mention "best seller", "10,000+ sold", or similar claims if
  truthful and compliant with Shopee policy.
- **Call to action**: End with "Add to cart now", "Follow our shop for new arrivals",
  or "Chat with us for bulk orders".
- **Local language**: In TH, ID, VN markets, write the description in the local
  language. In SG, MY, PH, English is primary but include local terms where relevant.

## Image Requirements

Images are critical on Shopee. The platform's mobile-first user base makes visual
content the primary conversion driver.

### Technical Specifications

| Specification | Requirement |
|--------------|-------------|
| Aspect ratio | 1:1 (square) or 2:3 (portrait, preferred for some categories) |
| Minimum resolution | 800 x 800 px |
| Recommended resolution | 1200 x 1200 px or 800 x 1200 px (2:3) |
| Maximum file size | 2 MB |
| Format | JPEG, PNG |
| Maximum images | 9 |
| Video | Supported and prioritized in search |

### Image Strategy

| Slot | Image Type | Purpose |
|------|-----------|---------|
| 1 | Main / cover | Clean product shot, may include minimal text banner |
| 2 | Feature highlights | Infographic with 3-5 key feature callouts |
| 3 | Lifestyle / in-use | Product being used in realistic setting |
| 4 | Size / dimensions | Product with measurements or scale reference |
| 5 | Material close-up | Detail shots showing quality and texture |
| 6 | Package contents | Everything included in the order |
| 7 | Color/variation display | All available colors or styles in one image |
| 8 | Social proof / reviews | Customer photos or testimonial highlights |
| 9 | Size chart or spec table | For apparel, accessories, furniture |

### Shopee Image Rules

- **Main image**: Unlike Amazon, Shopee allows light text overlays and colored
  backgrounds on the main image. However, clean images with minimal text tend to
  perform best.
- **No competitor logos or brand names** in images.
- **No contact information** (phone numbers, social media handles, website URLs).
- **No misleading images**: Product shown must match what the buyer receives.
- **Video priority**: Shopee's algorithm boosts listings with product videos. Aim for
  30-60 second videos showing the product in use.

### 2:3 Ratio Advantage

Shopee's mobile feed displays images in portrait orientation. A 2:3 ratio image
(800 x 1200 px) fills more screen space than a 1:1 square, resulting in:
- Higher visual prominence in search results and feed.
- More room for product detail in the image.
- Better mobile shopping experience.

Use 2:3 for main images and infographics. Use 1:1 for lifestyle and detail shots if
the composition does not suit portrait orientation.

## Category and Attribute Selection

Correct categorization is essential for Shopee SEO and for appearing in filtered
browse results.

### Category Selection Rules

- Choose the **most specific** category available. Shopee's category tree is deep;
  drill down to the leaf node.
- If the product fits multiple categories, choose the one with the highest traffic
  and relevance.
- Wrong category selection can lead to listing removal or reduced visibility.
- Check competitor listings to see which category top sellers use.

### Attribute Completion

Shopee provides category-specific attribute fields. Filling these is critical because:

1. **Search filters**: Buyers use attribute filters (brand, size, material, color) to
   narrow results. Missing attributes = invisible when filters are applied.
2. **Recommendation algorithm**: Shopee's recommendation engine uses attributes to
   match products to buyers.
3. **Listing quality score**: Shopee's internal scoring system rewards listings with
   complete attributes.

### Required Attributes (Common Across Categories)

| Attribute | Examples | Notes |
|-----------|----------|-------|
| Brand | Your brand or "No Brand" | Must be accurate; do not use competitor brands |
| Condition | New, Used | Most cross-border sellers list "New" |
| Ships from | Country of origin | Affects buyer trust and delivery estimate |
| Material | Cotton, Polyester, Stainless Steel | Category-dependent |
| Size | S, M, L, XL or exact measurements | Include a size chart image |
| Color | Actual color names | Match to variation names |
| Weight | Product weight in grams/kg | Affects shipping cost display |

### Attribute Optimization Tips

- Fill every available attribute field, even optional ones.
- Use the exact values from Shopee's dropdown menus when provided.
- If an attribute is free-text, include a relevant keyword naturally.
- Update attributes if Shopee adds new fields to your category.

## Variation Setup

Shopee variations allow buyers to select options (size, color, style) on a single
listing page. Well-configured variations improve conversion and reduce buyer confusion.

### Variation Structure

Shopee supports up to 2 variation tiers:

| Tier | Example | Notes |
|------|---------|-------|
| Tier 1 | Color: Black, White, Red | Primary variation shown as clickable options |
| Tier 2 | Size: S, M, L, XL | Secondary variation (creates a matrix) |

A 2-tier setup (e.g., Color x Size) creates a grid. Each combination can have its
own price, stock, and SKU.

### Variation Setup Rules

- **Unique images per variation**: Each Tier 1 option should have its own image showing
  that specific color or style.
- **Consistent naming**: Use standardized names (e.g., "Black" not "Blk" or "BLACK").
- **Price per variation**: Set different prices if costs differ (e.g., larger sizes may
  cost more). The lowest variation price is displayed in search results.
- **Stock per variation**: Track inventory at the variation level to avoid overselling.
- **SKU mapping**: Assign unique SKUs to each variation for inventory management.

### Pricing Strategy for Variations

- The **lowest variation price** appears in search results and category browse. Use this
  strategically: a lower entry price increases CTR.
- Do not create a fake low-price variation (e.g., a $1 "accessory only" option). Shopee
  penalizes this practice.
- Price differences between variations should be logical and proportional to size or
  material differences.

### Common Variation Mistakes

- **Too many variations**: More than 30-40 combinations confuse buyers and slow page load.
- **Missing variation images**: All variations showing the same image reduces trust.
- **Inconsistent pricing**: Random price jumps between similar variations raise suspicion.
- **Not using variations when applicable**: Listing each color as a separate product
  splits reviews and sales history.

## Shopee SEO

Shopee's search algorithm determines which products appear for any given keyword query.
Understanding its factors is essential for visibility.

### Search Algorithm Factors

| Factor | Weight | Description |
|--------|--------|-------------|
| Keyword relevance | Very High | Keyword match in title, description, and attributes |
| Sales volume | High | Recent sales count (last 30 days weighted heavily) |
| Conversion rate | High | Percentage of visitors who purchase |
| Recency | Medium | Newly listed or recently updated products get a temporary boost |
| Seller rating | Medium | Shop rating and response rate |
| Price competitiveness | Medium | Relative pricing within the category |
| Product rating | Medium | Star rating and number of reviews |
| Shopee Preferred / Mall status | Medium | Preferred and Mall sellers get ranking advantages |
| Listing completeness | Low-Medium | Filled attributes, multiple images, description quality |
| Response rate | Low | Chat response rate and response time |

### Keyword Research Tools

- **Shopee Search Bar Autocomplete**: Type a keyword and note the suggestions. These
  are high-volume search terms.
- **Shopee Keyword Ads Tool**: Available in Shopee Seller Centre under Marketing. Shows
  search volume, competition level, and recommended bid for keywords.
- **Shopee Popular Search**: Check trending keywords in your category.
- **Competitor Analysis**: Review titles and descriptions of top-ranking competitors
  for your target keywords.
- **Third-party tools**: DataEye, Kalodata, and others provide Shopee-specific
  keyword data.

### SEO Optimization Tactics

1. **Update listings regularly**: Shopee gives a recency boost. Edit the title,
   description, or images periodically.
2. **Boost listings**: Use Shopee's free "Boost" feature (5 products every 4 hours)
   to increase visibility.
3. **Respond to chat quickly**: Maintain a response rate above 90% and response time
   under 5 minutes.
4. **Encourage reviews**: Follow up with buyers (politely, per Shopee policy) to leave
   reviews with photos.
5. **Join campaigns**: Products enrolled in Shopee campaigns (flash deals, free shipping)
   receive algorithmic boosts.

## Shopee-Specific Features

### Vouchers

Shopee's voucher system is a key marketing tool. Types include:

| Voucher Type | Description | Best For |
|-------------|-------------|----------|
| Shop voucher | Discount for purchases in your shop | Increasing average order value |
| Product voucher | Discount on a specific product | Driving sales on key listings |
| Follow voucher | Discount for new followers | Growing shop follower count |
| Bundle deal voucher | Discount when buying multiple items | Clearing inventory, upselling |

**Voucher strategy**: Always have at least one active shop voucher. Common effective
structures include a small minimum spend (e.g., spend $20 get $2 off) and a higher
tier (spend $50 get $8 off) to encourage basket building.

### Flash Deals

Shopee flash deals are time-limited promotions featured on the Flash Deals page.

- Must offer a minimum discount (typically 10-20% depending on market).
- Limited slots; apply through Seller Centre.
- Products in flash deals get significant traffic boosts.
- Ensure sufficient stock before enrolling.
- Monitor flash deal performance and adjust pricing strategy accordingly.

### Free Shipping

Free shipping is one of the strongest conversion drivers on Shopee.

- **Shopee Free Shipping Program**: Seller subsidizes a portion; Shopee subsidizes the
  rest. Listings enrolled display the free shipping badge.
- **Seller-funded free shipping**: Set a minimum order amount to qualify.
- **Free shipping voucher**: Offer a shop voucher that covers shipping cost.

Shopee data consistently shows that listings with the free shipping badge convert at
significantly higher rates than those without it.

### Shopee Live

Livestream selling is integrated into the Shopee app and drives significant traffic.

- Schedule regular streams during peak hours (typically 8-11 PM local time).
- Feature products with exclusive live pricing.
- Pin products during the stream for easy add-to-cart.
- Interact with viewers; answer questions about the product in real time.
- Use the Shopee Live voucher feature to distribute time-limited discounts.

### Shopee Feed

Shopee's social media-style feed within the app.

- Post product updates, styling tips, behind-the-scenes content.
- Regular posting (3-5 times per week) improves shop visibility.
- Use the feed to drive traffic to new listings and promotions.

## Differences by Shopee Market

Each Shopee market has distinct buyer behavior, language requirements, and feature
availability. Tailor listings accordingly.

### Singapore (SG)

| Aspect | Details |
|--------|---------|
| Language | English primary, with some Chinese and Malay terms |
| Price sensitivity | Moderate; quality and brand awareness matter |
| Key categories | Electronics, beauty, home and living |
| Payment | Credit cards, ShopeePay, GrabPay common |
| Shipping expectations | 2-3 days domestic; international patience varies |
| Notes | Small market but high purchasing power; premium positioning can work |

### Malaysia (MY)

| Aspect | Details |
|--------|---------|
| Language | Bahasa Malaysia and English mixed; many listings bilingual |
| Price sensitivity | High; value for money is critical |
| Key categories | Fashion, beauty, home and living, electronics |
| Payment | Online banking, ShopeePay, COD in some areas |
| Shipping expectations | 3-5 days domestic; Shopee Preferred Seller badge important |
| Notes | Halal certification matters for food, cosmetics, and personal care |

### Thailand (TH)

| Aspect | Details |
|--------|---------|
| Language | Thai required; English secondary |
| Price sensitivity | High; strong promotion-driven culture |
| Key categories | Fashion, beauty, mobile accessories, home |
| Payment | Bank transfer, COD popular, ShopeePay growing |
| Shipping expectations | 3-7 days; COD common for first-time buyers |
| Notes | Flash deals and Shopee Live very popular; visual content critical |

### Philippines (PH)

| Aspect | Details |
|--------|---------|
| Language | Filipino and English; English widely understood |
| Price sensitivity | Very high; COD dominant |
| Key categories | Fashion, beauty, mobile accessories, home essentials |
| Payment | COD is the dominant payment method; GCash growing |
| Shipping expectations | 5-10 days; logistics can be challenging outside Metro Manila |
| Notes | Free shipping is critical for conversion; bundle deals popular |

### Indonesia (ID)

| Aspect | Details |
|--------|---------|
| Language | Bahasa Indonesia required |
| Price sensitivity | Very high; the largest and most price-sensitive SEA market |
| Key categories | Fashion (Muslim fashion large segment), beauty, electronics, FMCG |
| Payment | Bank transfer, COD, ShopeePay, e-wallets (OVO, Dana, GoPay) |
| Shipping expectations | 3-7 days Java; 7-14 days outer islands |
| Notes | Largest Shopee market by GMV; must have competitive pricing; Ramadan is peak season |

### Vietnam (VN)

| Aspect | Details |
|--------|---------|
| Language | Vietnamese required |
| Price sensitivity | High; strong promotion culture |
| Key categories | Fashion, beauty, electronics, mother and baby |
| Payment | COD dominant; bank transfer and e-wallets growing |
| Shipping expectations | 3-5 days major cities; 7+ days rural |
| Notes | Fast-growing market; Shopee Live adoption high; competitive pricing essential |

### Taiwan (TW)

| Aspect | Details |
|--------|---------|
| Language | Traditional Chinese required |
| Price sensitivity | Moderate; quality and brand matter |
| Key categories | Fashion, beauty, electronics, food |
| Payment | Credit card, convenience store payment, ATM transfer |
| Shipping expectations | 1-3 days domestic (small geography); convenience store pickup popular |
| Notes | Mature e-commerce market; listing quality expectations higher; 7-day return policy standard |

### Cross-Market Listing Tips

- **Never use one listing across all markets**: Translate and localize per market.
- **Adjust pricing per market**: Factor in local competition, shipping costs, and
  purchasing power.
- **Adapt image text**: If infographics contain text, translate for each market.
- **Research local competitors**: Top sellers in ID are different from top sellers in SG.
- **Calendar awareness**: Sale dates differ by market (9.9, 11.11, 12.12 are universal;
  Ramadan in ID/MY, Songkran in TH, Tet in VN are market-specific peaks).
