# Peak Season Preparation Checklist

A detailed countdown checklist for preparing, executing, and analyzing peak
shopping events. Use this as a task tracker for every major event (Prime Day,
Black Friday, 11.11, 12.12, and other significant sales periods).

Copy this checklist into your project management tool at T-90 and work through
it systematically. Each phase has a clear deadline, specific tasks, and
verification steps.

## T-90 Days: Strategic Planning

This is the most critical phase. Decisions made here determine 80% of your
peak-season outcome. Do not rush this phase.

### Performance Review

- [ ] Pull last year's sales data for the same event period (total revenue,
      units sold per SKU, conversion rate, average order value)
- [ ] Pull last year's advertising data (total spend, ACoS, TACoS, top
      keywords by ROAS, worst keywords by ROAS)
- [ ] Pull last year's inventory data (starting stock, ending stock, days of
      stockout per SKU, excess inventory remaining post-event)
- [ ] Review last year's post-mortem document and action items
- [ ] Identify top 3 wins and top 3 failures from the prior year event
- [ ] Document what changed since last year (new competitors, algorithm
      changes, new platform features, category trends)

### Product Selection

- [ ] Select 3-5 hero SKUs for primary promotional investment. Criteria:
      - 4.0+ star rating with 50+ reviews
      - Proven 60+ day sales history
      - Healthy margin (30%+ gross margin after COGS and shipping)
      - Sufficient supplier capacity to produce peak inventory
- [ ] Identify 5-10 secondary SKUs for lighter promotion (coupons, small
      discounts, cross-sell from hero SKU traffic)
- [ ] Decide on any new product launches timed to the event. Caution: launching
      an unproven product during peak season is high risk. Only proceed if you
      have 30+ reviews and 60+ days of data by T-Day.
- [ ] Define bundle or multi-pack offers if applicable

### Supplier and Production Orders

- [ ] Calculate peak inventory requirement for each hero SKU using the seasonal
      demand multiplier (see SKILL.md Inventory Pre-positioning section)
- [ ] Submit purchase orders to suppliers with confirmed delivery dates
- [ ] Negotiate payment terms for larger-than-usual orders (e.g., 30/70 split:
      30% deposit, 70% before shipment)
- [ ] Confirm supplier capacity and production schedule in writing
- [ ] For CNY-affected events (Q1): verify factory closure dates and adjust
      order timing (see SKILL.md CNY section)
- [ ] Identify backup suppliers for hero SKUs in case primary supplier delays

### Budget Planning

- [ ] Set total peak-season budget broken down by:
      - Inventory procurement: ___
      - Freight and logistics: ___
      - Advertising: ___
      - Promotions and deals (platform fees, coupon costs): ___
      - Customer service (temporary staff): ___
      - Contingency reserve (10-15% of total): ___
- [ ] Get budget approved by stakeholders / finance
- [ ] Set target metrics:
      - Revenue target: ___
      - ACoS target: ___
      - TACoS target: ___
      - Minimum acceptable ROAS: ___
      - Maximum acceptable return rate: ___

### Verification

- [ ] All hero SKUs have purchase orders placed
- [ ] Budget is approved and documented
- [ ] Prior year post-mortem has been reviewed and action items addressed
- [ ] Event-specific goals and targets are documented and shared with team

## T-60 Days: Logistics and Preparation

Focus shifts to physical execution: getting inventory in place and beginning
research for the campaign.

### Inventory Shipping

- [ ] Confirm production is on schedule for all hero SKU orders
- [ ] Arrange freight booking (ocean, air, or rail) with confirmed departure
      dates
- [ ] For ocean freight: verify that departure date allows arrival at FBA with
      14+ day buffer before T-Day
- [ ] Prepare all shipping documentation (commercial invoice, packing list,
      customs paperwork, FNSKU labels)
- [ ] Ship first batch of inventory to FBA / destination warehouse
- [ ] Set up shipment tracking and check-in schedule (monitor status every
      3 days)

### FBA Capacity Check

- [ ] Review current FBA restock limits in Seller Central > Inventory
      Performance
- [ ] If restock limits are insufficient for peak inventory, take action:
      - Improve IPI score (clear stranded inventory, liquidate aged stock)
      - Split shipments to multiple fulfillment centers
      - Consider 3PL backup for overflow inventory
- [ ] Verify FBA receiving times for your target fulfillment centers (check
      recent shipment receiving durations)

### Keyword Research

- [ ] Run keyword research using Helium 10, Brand Analytics, or equivalent tool
- [ ] Identify seasonal keywords that spike during the event period (compare
      search volume trends year-over-year)
- [ ] Build keyword lists organized by:
      - Hero SKU primary keywords (exact match targets)
      - Seasonal modifier keywords (e.g., "black friday deal," "christmas gift
        for mom")
      - Competitor brand keywords (if running Sponsored Products competitor
        targeting)
      - Long-tail keywords for lower-competition wins
- [ ] Check search volume trends on Google Trends for keyword timing validation

### Promotional Strategy

- [ ] Define discount depth for each hero SKU:
      - Calculate breakeven discount (maximum discount that maintains positive
        unit margin after ad spend)
      - Set promotional price at or above breakeven
- [ ] Submit deal applications to Amazon (Lightning Deals, Best Deals) if
      applicable. Note: Amazon requires 4-6 week lead time for deal approvals.
- [ ] Plan coupon strategy for secondary SKUs
- [ ] For Shopee/Lazada: register for platform promotions, voucher programs,
      and flash sale slots through Seller Center

### Customer Service Preparation

- [ ] Estimate peak message volume (normal volume x 2-4x multiplier)
- [ ] Hire or contract temporary CS staff if needed (allow 2 weeks for training)
- [ ] Begin creating/updating canned responses for top 10 anticipated questions
- [ ] Brief CS team on upcoming event, expected volume, and product details

### Verification

- [ ] Inventory is shipped or has a confirmed ship date within the next 7 days
- [ ] FBA capacity is sufficient or contingency plan is in place
- [ ] Keyword lists are built and organized
- [ ] Deal applications are submitted to the platform
- [ ] CS team is briefed and staffing plan is confirmed

## T-45 Days: Content and Campaign Build

Build all creative assets and campaign structures. Nothing goes live yet --
everything is prepared and staged.

### Listing Optimization

- [ ] Update backend search terms with seasonal keywords for each hero SKU
- [ ] Add 1-2 seasonal phrases to bullet points (keep changes minimal to avoid
      triggering listing review)
- [ ] Do NOT change the main title -- seasonal terms go in backend only
- [ ] Review and update main product images (add seasonal lifestyle image if
      applicable, ensure white background main image meets platform requirements)
- [ ] Update A+ content with one seasonal module (gift guide, holiday use case,
      seasonal styling)

### Brand Store / Shop Page

- [ ] Design seasonal landing page in Amazon Brand Store (or Shopee/Lazada
      shop page)
- [ ] Feature hero SKUs prominently with deal pricing displayed
- [ ] Add navigation to seasonal collection from store homepage
- [ ] Test all links and product tiles in the store page
- [ ] Schedule store page to go live at T-14

### Social Media Content

- [ ] Draft social media posts for pre-event, event day, and post-event phases
- [ ] Create visual assets (product images, lifestyle shots, deal graphics)
- [ ] Schedule posts across platforms (Instagram, TikTok, Facebook, Pinterest)
- [ ] If using TikTok Shop or Shopee Live: schedule live selling sessions for
      T-Day and plan content/script

### Advertising Campaign Setup

- [ ] Build all campaign structures (keep paused):
      - Sponsored Products: exact match campaigns for hero SKU primary keywords
      - Sponsored Products: broad/phrase match campaigns for discovery
      - Sponsored Products: auto campaigns for each hero SKU
      - Sponsored Brands: headline search ads with seasonal creative
      - Sponsored Brands Video: product demo videos targeting hero keywords
      - Sponsored Display: retargeting audiences and competitor product targeting
- [ ] Set initial bids at 1.5x your normal CPC (will adjust during ramp phase)
- [ ] Set daily budgets at normal levels (will increase during ramp phase)
- [ ] Configure negative keywords to prevent wasted spend
- [ ] Double-check campaign targeting, bid strategy, and budget caps

### Verification

- [ ] All listing updates are live and indexed (search for seasonal terms to
      confirm)
- [ ] Brand store seasonal page is built and preview link works
- [ ] All advertising campaigns are built, paused, and ready to activate
- [ ] Social media content is scheduled
- [ ] No listing suppressions or policy warnings on hero SKUs

## T-30 Days: Early Activation

Begin testing at low spend to gather data before peak traffic arrives.

### Early Advertising

- [ ] Activate auto campaigns and broad-match campaigns at 20-30% of normal
      daily budget
- [ ] Monitor performance daily for the first 7 days
- [ ] Harvest converting search terms from auto/broad campaigns and add to
      exact-match campaigns
- [ ] Identify and negate non-converting terms that are wasting budget
- [ ] Test Sponsored Brands creative variations (run 2-3 headline variants)

### Review Velocity

- [ ] Enroll hero SKUs in Amazon Vine (if eligible and not already enrolled)
- [ ] Activate post-purchase email sequences requesting reviews (within
      Amazon's policies)
- [ ] Check review count and rating for each hero SKU. Target: 50+ reviews
      and 4.0+ stars by T-Day.
- [ ] If any hero SKU has fewer than 30 reviews, consider whether to proceed
      with it as a hero or demote to secondary

### Campaign Mechanics Testing

- [ ] Test all coupon codes (create test order if needed, cancel afterward)
- [ ] Verify deal pricing displays correctly on the listing
- [ ] Test Brand Store links from advertising campaigns
- [ ] Verify that Sponsored Brands ad creative matches current listing
- [ ] Test social media links to product pages
- [ ] Check mobile experience for all listings (majority of peak traffic is
      mobile)

### Inventory Arrival Verification

- [ ] Confirm inventory shipments have arrived at destination port
- [ ] Track customs clearance status
- [ ] Verify units are checked in at FBA (status = "Available," not
      "Receiving" or "In Transit")
- [ ] If units are delayed, activate contingency:
      - Switch to FBM fulfillment from 3PL backup stock
      - Consider air freighting critical SKUs if ocean shipment is delayed
- [ ] Calculate days of supply at projected peak sell-through rate for each
      hero SKU. Minimum target: 21 days of supply at T-Day.

### Verification

- [ ] Early advertising campaigns are running and gathering data
- [ ] Review counts are on track (50+ per hero SKU)
- [ ] All campaign mechanics tested and working
- [ ] Inventory is in FBA with "Available" status
- [ ] No hero SKU has fewer than 14 days of supply at projected peak rate

## T-14 Days: Budget Ramp and Final Checks

The final preparation push. After this phase, you are in execution mode.

### Advertising Activation

- [ ] Unpause all remaining campaigns (exact match, Sponsored Brands,
      Sponsored Display)
- [ ] Increase daily budgets to 1.5x normal (week 1 of ramp)
- [ ] Plan budget increase to 2-3x normal at T-7
- [ ] Review bid recommendations from platform and adjust selectively
- [ ] Activate dayparting rules if using third-party tools (increase bids
      during peak shopping hours, typically 7-11 PM local time)

### Promotional Deal Activation

- [ ] Verify all Lightning Deals and Best Deals are approved and scheduled
- [ ] Activate coupons on all promoted SKUs
- [ ] Confirm promotional pricing is live on the listing (check the actual
      customer-facing page, not just Seller Central)
- [ ] For Shopee/Lazada: confirm voucher allocation and flash sale slot timing

### Final Inventory Check

- [ ] Pull current inventory snapshot for all hero and secondary SKUs
- [ ] Calculate days of supply at projected peak daily sales rate:
      - If < 14 days: activate contingency (FBM backup, price increase to
        slow demand, or air freight emergency shipment)
      - If 14-30 days: proceed as planned
      - If > 45 days: you may have over-ordered; plan post-event liquidation
        now
- [ ] Verify no hero SKUs are stranded, suppressed, or have listing issues
- [ ] Confirm FBM backup fulfillment is ready (3PL stock available, shipping
      templates configured)

### Team Readiness

- [ ] Hold pre-event briefing with all team members (advertising, CS, ops)
- [ ] Share event monitoring dashboard and reporting schedule
- [ ] Assign roles for T-Day monitoring:
      - Advertising monitor: adjusts bids and budgets every 4 hours
      - Inventory monitor: checks stock levels every 6 hours
      - CS lead: manages message queue and escalations
      - Competitor monitor: tracks competitor pricing and deals
- [ ] Confirm team availability for T-Day and T+1 (no vacations, no conflicts)
- [ ] Test communication channels (Slack, WhatsApp group, email)

### Verification

- [ ] All advertising campaigns are live and delivering impressions
- [ ] All promotional deals and coupons are active and displaying correctly
- [ ] Inventory levels are sufficient for projected peak demand
- [ ] Team is briefed, roles assigned, and available for T-Day
- [ ] Monitoring dashboard is set up and accessible to all team members

## T-Day: Peak Execution

This is execution, not planning. Every action should be reactive and data-driven.

### Hourly Monitoring

- [ ] Set up monitoring schedule (every 1-2 hours during peak hours):
      - Total sales (revenue and units)
      - Ad spend and ACoS (by campaign)
      - Conversion rate (vs. normal baseline)
      - Inventory remaining (by SKU)
      - Customer message volume
- [ ] Track metrics in a shared dashboard (Google Sheets, Sellerboard, or
      equivalent) with hourly data points

### Advertising Management

- [ ] Review campaign performance every 4 hours
- [ ] Increase bids by 20-50% on campaigns with ACoS below target and
      high impression share
- [ ] Decrease bids or pause campaigns with ACoS above 2x target
- [ ] Monitor budget utilization -- if campaigns are running out of budget
      before end of day, increase daily budget by 50%
- [ ] Check for any campaigns that failed to deliver (zero impressions) and
      troubleshoot immediately (common causes: bid too low, budget depleted,
      listing suppressed)

### Inventory Monitoring

- [ ] Check inventory levels every 6 hours for hero SKUs
- [ ] If any SKU drops below 3 days of supply at current sell rate:
      - Activate FBM backup fulfillment immediately
      - Consider raising price by 10-15% to slow demand
      - Do NOT run out of stock on T-Day if avoidable
- [ ] Track sell-through rate vs. forecast hourly

### Customer Service

- [ ] Dedicated CS team monitoring messages with target < 4 hour response time
- [ ] Escalation process active for negative reviews, A-to-Z claims, and
      order issues
- [ ] Monitor Seller Central Account Health dashboard for any alerts
- [ ] Track common customer issues and update canned responses in real-time
      if new patterns emerge

### Competitor Monitoring

- [ ] Check top 3-5 competitors every 4 hours for:
      - Price changes
      - New deal badges (Lightning Deal, Coupon, etc.)
      - New advertising placements (Sponsored Brands, top-of-search)
      - Stock status (competitor stockout = opportunity to increase bids)
- [ ] Decide response strategy:
      - Competitor drops price below yours: match only if margin allows;
        otherwise differentiate on reviews, content, or bundle value
      - Competitor stocks out: increase bids on their branded keywords

### End-of-Day Summary (T-Day)

- [ ] Compile T-Day results:
      - Total revenue vs. target: ___
      - Total ad spend vs. budget: ___
      - Blended ACoS: ___
      - Units sold per hero SKU: ___
      - Inventory remaining per hero SKU: ___
      - Customer messages received: ___
      - Notable competitor activity: ___
- [ ] Share summary with team
- [ ] Identify any issues requiring overnight action

## T+7 Days: Wind Down

Transition from peak mode back to normal operations while capturing early
insights.

### Advertising Wind Down

- [ ] Reduce daily budgets by 30% on T+1, returning to 1.5x normal
- [ ] Reduce to normal budget levels by T+5
- [ ] Pause seasonal keyword campaigns that are no longer converting
- [ ] Keep exact-match campaigns on proven winners active at normal bids
- [ ] Pull preliminary advertising report: spend, sales, ACoS by campaign

### Initial Performance Analysis

- [ ] Compile top-line metrics for the event period:
      - Total revenue: ___
      - Total units sold: ___
      - Total ad spend: ___
      - Blended ACoS: ___
      - TACoS: ___
      - Conversion rate (event period vs. normal): ___
- [ ] Compare results to targets set at T-90
- [ ] Identify top 3 performing SKUs and bottom 3 performing SKUs
- [ ] Calculate actual seasonal multiplier (actual sales / normal period sales)
      for use in next year's planning

### Returns Preparation

- [ ] Review return rate for event-period orders (check after 3-5 days)
- [ ] If return rate exceeds 15%, investigate:
      - Product quality issues (check recent negative reviews)
      - Listing accuracy (did promotional copy create wrong expectations?)
      - Gift returns (expected for holiday events)
- [ ] Ensure CS team has capacity for increased return inquiries
- [ ] Pre-authorize return resolutions for common issues to reduce handling
      time

### Inventory Assessment

- [ ] Pull current inventory levels for all promoted SKUs
- [ ] Calculate remaining days of supply at post-event normal sell rate
- [ ] Flag SKUs with > 60 days of supply post-event as overstock risk
- [ ] For overstock SKUs: decide between continued promotion, off-Amazon
      liquidation, or FBA removal (see inventory-management SKILL.md
      Overstock Liquidation Options)

### Listing Reversion

- [ ] Begin removing seasonal keywords from backend search terms
- [ ] Revert seasonal bullet point changes to evergreen copy
- [ ] Schedule A+ content reversion to evergreen version by T+14
- [ ] Keep Brand Store seasonal page live through T+14 (captures late traffic)

### Verification

- [ ] Ad budgets are stepped down to near-normal levels
- [ ] Initial performance metrics are compiled and shared
- [ ] Return rate is being monitored
- [ ] Overstock SKUs are identified with action plan

## T+14 Days: Post-Mortem Review

The final phase. The quality of this analysis determines whether next year's
event is better or worse.

### Full Performance Analysis

- [ ] Pull complete data set for the event period (T-7 through T+7 to capture
      pre-event ramp and post-event tail):
      - Revenue by SKU (daily breakdown)
      - Ad spend by campaign (daily breakdown)
      - Conversion rate by SKU (daily breakdown)
      - Inventory levels (daily breakdown)
      - Customer messages and return requests (daily breakdown)
- [ ] Calculate final metrics:
      - Total event revenue: ___
      - Total event profit (after COGS, shipping, ads, fees, returns): ___
      - Event ROAS: ___
      - Inventory forecast accuracy: (forecast units / actual units sold) x 100
      - Customer satisfaction: return rate, negative review rate, CS response
        time

### SKU-Level Post-Mortem

For each hero SKU, document:

- [ ] Sales result vs. target (hit / missed / exceeded by what %)
- [ ] Ad efficiency (ACoS vs. target, top 5 keywords, bottom 5 keywords)
- [ ] Inventory outcome (stocked out? excess remaining? accurate forecast?)
- [ ] Promotional effectiveness (did the discount drive incremental volume or
      just cannibalize full-price sales?)
- [ ] Return rate and reasons
- [ ] Competitive position (did we gain or lose share vs. top competitors?)

### Advertising Deep Dive

- [ ] Identify top 10 keywords by ROAS -- these are your proven winners for
      next event
- [ ] Identify bottom 10 keywords by ROAS -- add to negative keyword list
- [ ] Analyze campaign type effectiveness:
      - Sponsored Products ACoS: ___
      - Sponsored Brands ACoS: ___
      - Sponsored Display ACoS: ___
- [ ] Compare peak CPCs to pre-event CPCs to calibrate next year's bid
      strategy
- [ ] Evaluate Sponsored Brands creative performance (which headlines and
      images won)

### Inventory Reconciliation

- [ ] Compare forecast sell-through vs. actual sell-through for each SKU
- [ ] Calculate forecast accuracy percentage
- [ ] If forecast was off by > 20%, identify the root cause:
      - Demand was higher than expected: increase multiplier for next event
      - Demand was lower than expected: decrease multiplier or investigate
        (pricing too high? competitor took share? listing issue?)
      - Supply was delayed: add buffer to lead time for next event
- [ ] For excess inventory: execute liquidation plan by T+30 to avoid
      long-term storage fees
- [ ] Update seasonal demand multipliers for next year based on actual data

### Document Learnings

- [ ] Write a 1-page event post-mortem covering:
      - Executive summary (3-5 key takeaways)
      - What worked (top 3 wins with supporting data)
      - What failed (top 3 failures with root cause analysis)
      - Specific changes for next event (actionable, with assigned owners)
- [ ] Store post-mortem in a shared location accessible to the team
- [ ] Update the seasonal planning playbook with revised timelines, budget
      allocations, keyword lists, and multipliers
- [ ] Schedule a team debrief meeting to review findings and align on next
      steps

### Next Event Planning

- [ ] Review the campaign calendar for the next major event
- [ ] Set tentative T-90 planning start date for the next event
- [ ] Carry forward action items from this post-mortem into the next event's
      T-90 checklist
- [ ] Archive all raw data (sales reports, ad reports, inventory reports) for
      year-over-year comparison

### Verification

- [ ] Full post-mortem document is written and shared
- [ ] Inventory reconciliation is complete
- [ ] Excess inventory liquidation plan is active
- [ ] Seasonal playbook is updated with revised data
- [ ] Next event planning date is on the calendar
