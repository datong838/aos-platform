# 抖店运营技能路由

先判定目标，不把“查看、分析、执行”混成一次任务。

- 摸菜单、找页面、复查页面数据：`douyin-store-platform-observation`。
- 做全店画像、专题诊断、问题归因、方案设计：`douyin-store-business-diagnosis`。
- 形成可审计事实卡、截图索引、冲突与 nonClaims：`douyin-store-evidence-capture`。
- 明确要求执行单一外部动作：`douyin-store-controlled-operation`；必须重新确认目标与授权。

默认只读。平台推荐、行业榜单、预估提升、能力入口和店铺实际配置、使用、效果必须分开记录。
