# 栖月汇管理后台观察

先读 [后台导航地图](references/admin-navigation-map.md) 和 [观察配方](references/admin-observation-recipes.md)。

## 前置

1. 用户已在现有浏览器手动登录并明确允许观察。
2. 确认页面属于栖月汇目标店铺；多标签或多账号时不得猜。
3. 默认只读：允许导航、滚动、分页、筛选、展开和截图；禁止保存、发布、删除、发货、退款、转账、升级和配置修改。

## 观察顺序

按经营链而非菜单顺序：商品、订单履约、会员、推广分润、内容、经营控制。

## 页面完成门

一个页面只有在记录了页面目的、业务对象、筛选/时间窗、下钻、空态/部分态、可见操作、数据语义和下一跳后才算摸清。菜单和页面都可能有独立滚动容器，必须分别检查。

## 立即停止

登录失效、验证码、风控、目标店铺不明、出现密钥/密码/完整支付材料，或操作将触发写入、购买、发送、结算时立即停止。

## 输出

输出页面地图增量、观察事实、未知、待对账对象和下一观察配方；不把按钮存在写成能力已运行。
