# 栖月汇后台导航地图

入口：`https://yanpanji.com/shop.html#url=...`。登录由用户完成；不要记录认证材料。

| 一级域 | 已知内容 | 直接用途 |
|---|---|---|
| 概况 | 基础经营概览 | 快速判断数据截止和异常，不作深度归因 |
| 店铺 | 店铺/小程序配置、装修 | 理解消费者端配置来源 |
| 商品 | 商品、分类、规格、库存、价格、会员价、端可见 | 商品结构与供给画像 |
| 订单 | 商城订单、卡订单、线下支付、退款、发货、自提、核销、评价 | 交易与履约漏斗 |
| 会员 | 会员、等级、资产、标签、分群、关系 | 客户和店主画像 |
| 营销 | 券、奖励、活动、推广能力 | 区分存在/配置/使用/效果 |
| 财务 | 佣金、结算、逆转、提现/发票等 | 单位经济与对账 |
| 数据 | 今日/周期基础指标 | 基础看盘，需跨域补强 |
| 设置 | 人员、角色、日志、支付、配送、公开端配置、系统 | 组织与治理；敏感配置见即停止 |
| 内容管理 | 文章、帮助、公告、素材、草稿、分类 | 内容教育与商品承接 |

## 直接定位表

| 想看什么 | 语义路径 | 到页后先看 |
|---|---|---|
| 商城正式订单 | 订单 → 订单管理 → 商城订单 | 来源、支付、商品行、履约方式、订单状态 |
| 会员卡订单 | 订单 → 订单管理 → 会员卡选购订单 | 卡商品、会员、支付和权益状态 |
| 退款售后 | 订单 → 订单管理 → 退款维权 | 行级售后、退款状态和时间 |
| 发货/自提/核销 | 订单 → 订单处理 → 发货/自提/核销 | 待办量、超时、状态迁移 |
| 商品结构 | 商品 → 商品管理/商品列表 | 上下架、SPU、价格带、库存、分类 |
| 多规格 SKU | 商品列表 → 选择复杂正式商品 → 编辑 | 规格轴、SKU 组合、价格、库存、图片 |
| 会员价/引流品 | 商品编辑 → 价格/会员/分享体验相关区域 | 适用等级、主品与引流品关系、配额 |
| 会员与店主 | 会员 → 会员列表/等级/标签/分群 | 资格、等级、资产、关系与活跃候选 |
| 营销工具 | 营销 → 营销概况/具体工具 | 可用性、版本限制、配置、真实使用 |
| 优惠券/奖励 | 营销 → 券/奖励相关工具 | 领取、赠送、核销、过期和订单引用 |
| 分润与佣金 | 财务 → 佣金/结算相关页面 | 待结算、已结算、逆转、规则与订单关系 |
| 经营数据 | 数据 → 概况/周期数据 | cutoff、口径、趋势、能否下钻 |
| 内容知识 | 向下滚动一级菜单 → 内容管理 → 文章/帮助/素材 | 分类、发布状态、商品关联和内容新鲜度 |
| 小程序装修 | 店铺 → 装修/DIY 管理 | 首页组件、导航、内容与商品配置 |
| 人员与审计 | 设置 → 人员/角色/操作日志 | 分工、权限、实际运营节奏 |

定位时优先使用这张语义表；只有需要自动打开明确页面时才依赖 hash 路由。页面改版后先更新“页面标题 + 中文菜单 + 关键区块”锚点，再更新路由。

## 已知稳定直达语义

- 订单列表：`shop/order/lists`。
- 商品编辑：`shop/goods/editGoods&goods_id=<id>`；`goods_id=56` 曾用于观察多规格语义，ID 只作实例定位，不代表标准样本。
- 装修管理：`shop/diy/management`。

其余页面优先按“左侧菜单中文名称 + 页面标题 + hash 中的业务段”定位。未知 hash 首次观察后再补地图，不猜内部路由。

左侧菜单、二级菜单和主内容区可能分别滚动。先确认当前焦点，再滚动；不要把“屏幕底部”误认为菜单结束或列表结束。
