# 后台观察配方

## 商品与多规格

1. 从商品列表选择有多个规格/价格/库存的正式商品。
2. 打开编辑页但不修改，完整滚动。
3. 记录 SPU、规格轴、SKU 组合、价格/会员价、库存、端可见和引流商品配置。
4. 与 Goods/GoodsSku/GoodsWeapp/ShareLead 数据语义对账。

## 订单与履约

使用正式业务单理解状态，测试单只用于页面结构。记录支付、商品行、配送/自提、发货/核销、售后和时间，但不转录姓名、电话、地址、订单号或支付号。

## 会员与推广

记录会员总览、等级、标签/分群、店主资格、分享/客户/收益入口的结构；个体明细默认不读取。重点建立资格→分享→绑定→成交→持续活跃漏斗。

## 营销与财务

对每项能力分别标记：`EXISTS / CONFIGURED / USED / EFFECT_OBSERVED / RESTRICTED`。佣金按待结算、已结算、逆转和成本维度观察。
