# 方案比较与八工作台交接

| 方案域 | 主工作台 | 典型输出 |
|---|---|---|
| 全店组合决策 | 经营参谋 | Problem/Opportunity/SolutionPortfolio/GrowthPlan 草案 |
| 订单/体验履约 | 统一运营 | 异常分诊、履约任务、对账 |
| 内容/活动 | 内容与活动 | 内容 Brief、活动方案、评审 |
| 店主激活 | 达人邀约 | 分层、激活、关系履约 |
| 媒体素材 | 多媒体 | 海报、视频、商品教育资产 |
| 客户培育 | 客户关系 | 分群、同意、体验跟进、复购旅程 |
| 价格/佣金/利润 | 价格治理 | 单位经济、ImpactPreview、价格/佣金方案 |
| 长程协同 | 日常总控 | Task DAG、Checkpoint、Review、Handoff |

每个方案比较预期收益、投入、周期、风险、依赖、可逆性、先行指标、结果指标、护栏和停止条件。经营分析只提交草案，审批后才 materialize Task；外部副作用另经 Proposal→Approval→Lease→Receipt→Reconcile。
