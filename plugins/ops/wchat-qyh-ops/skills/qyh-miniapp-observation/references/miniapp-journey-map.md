# 栖月汇消费者端旅程地图

| 旅程 | 已观察能力 | 要回答的经营问题 |
|---|---|---|
| 首页/搜索/分类 | 商品发现、轮播、公告、分类、瀑布流 | 客户怎样发现商品 |
| 内容/文章 | 领域知识、文章、关联商品 | 内容是否建立理解和信任 |
| 商品详情 | 多规格、价格、库存、收藏、海报、分享、购买 | 信息是否支持决策 |
| 购物车/结算 | 选品、数量、会员价、推荐、结算 | 转化在哪里流失 |
| 会员中心 | 等级、余额、积分、券、订单、通知 | 客户资产是否被经营 |
| 我的店铺 | 二维码、体验分享、收益、分享、客户 | 店主是否被激活并持续经营 |
| 优惠券 | 持有、使用、赠送 | 赠券是否带来有效触达和成交 |
| 体验码 | 赠送、0 元真实下单、履约 | 体验是否形成客户和长期价值 |

## 直接定位旅程

| 想看什么 | 点击路径 |
|---|---|
| 商品多规格与分享 | 首页/分类 → 正式复杂商品 → 规格选择/海报/分享 |
| 内容怎样承接商品 | 首页内容区 → 文章详情 → 关联商品入口 |
| 购物决策 | 商品详情 → 加入购物车 → 购物车（停在支付前） |
| 会员资产 | 底部“我的” → 会员等级/余额/积分/券/订单 |
| 个人店铺与客户 | 底部“我的” → 我的店铺 → 二维码/分享/客户 |
| 收益结构 | 我的店铺 → 我的收益 | 只看状态和字段，不记录个人金额 |
| 体验赠送 | 我的店铺 → 分享体验 | 只看可用权益和流程，不实际发送 |
| 券赠送 | 我的 → 优惠券 → 可赠送入口 | 只验证交互，不选择接收人或发送 |

微信桌面中先搜索/打开“栖月汇”小程序；确认当前登录身份属于用户允许的观察上下文。若用户切换账号或小程序重新授权，立即重新确认 scope。

每个旅程记录入口、前置身份、核心对象、可见决策、下一步、退出点、分享点、证据和未知。

不得推断：可分享≠已传播；自动成为店主≠活跃经营；客户绑定≠已服务或复购；有收益入口≠高佣有效；有内容≠内容影响成交。
