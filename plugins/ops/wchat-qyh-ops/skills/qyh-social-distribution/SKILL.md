# 栖月汇社交分销与体验增长

先读 [机制模型](references/distribution-mechanism.md) 和 [诊断清单](references/distribution-diagnostics.md)。

## 核心原则

> 分佣比例不是增长机制；增长来自合适商品、可信内容、目标客户、真实劳动、完整体验、后续服务和可持续单位经济的组合。

## 五条链分别分析

1. 消费者 → 店主资格 → 首次经营行动；
2. 分享者 → 访问者 → 客户绑定 → 首单/复购；
3. 主商品订单 → 体验名额 → 体验码 → 体验订单 → 履约；
4. 内容/优惠券/商品 → 分享 → 互动 → 成交；
5. 推广订单 → 佣金 → 待结算 → 已结算/逆转 → 净收益。

## 方法

对每条链建立分母明确的漏斗、cohort、时间窗、成本、异常和替代解释。不要用店主数、分享按钮、客户总数或佣金比例替代真实活跃与增量效果。

## 治理

“客户永久归属”先标记业务规则，需要合同、实现、客户知情、变更/争议和合规核验。不得将个人收益或推广困难推广为全平台结论。
