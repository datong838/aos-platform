# 栖月汇分销机制模型

## 消费即店主

下单后获得店主资格和个人店铺入口。分析必须使用：资格 → 看见入口 → 首分享 → 首绑定 → 首成交 → 持续活跃漏斗。

## 分享体验

```text
主商品购买
  → 产生引流品体验权益
  → 推广者赠送体验码
  → 受赠者看到真实商品价值并以 0 元完成真实订单
  → 履约/体验
  → 客户关系与复购候选
```

它不同于普通券：有母单、权益实例、体验子单、履约和关系归属。

## 优惠券与内容

券可赠送，知识内容可关联商品，商品/分类/海报/小程序可分享。要核验曝光、领取、阅读、点击、加购、成交和复购，而不是入口存在。

## 佣金

区分推广、客户维护、技术服务等口径；区分待结算、已结算和逆转。推广者净收益需要扣除体验、内容、触达、时间、维护和退款成本。
