# 微信小店运营研究插件

本插件把微信小店后台的页面能力、稳定定位方式、全店经营研究方法和安全操作门固化为可复用技能。它面向多个微信小店经营实体，不绑定某一家店铺，也不保存账号、Cookie、Token、手机号、地址或订单明细。

## 技能

- `wx-store-ops-router`：按问题选择最小技能组合。
- `wx-store-platform-observation`：从菜单地图直接定位页面，完成只读观察。
- `wx-store-business-diagnosis`：把平台页面证据组织为经营画像、问题机会和方案候选。
- `wx-store-controlled-operation`：获得明确授权后执行单目标、可回读、可停止的操作。

默认只读。平台具备某项功能，不代表目标店铺已配置、使用或产生效果；遮罩、空白、加载中、权限不足均不得解释为业务值 0。
