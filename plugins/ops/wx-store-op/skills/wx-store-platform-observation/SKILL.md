# 微信小店后台只读观察

先读 [导航地图](references/navigation-map.md) 和 [观察规程](references/observation-playbook.md)。

## 观察顺序

1. 首页与店铺信息：确认实体、行业、经营时长、体验与诊断。
2. 商品与订单：确认在售、下架、价格带、曝光、成交、履约和历史体量。
3. 推荐、搜索、营销：确认自然曝光、搜索意图、工具配置和真实效果。
4. 用户、推广、联盟：确认老客、会员、投流、达人/机构、佣金和合作状态。
5. 资金、数据、服务：确认权限、口径、结算和外部服务能力。

每个正常页面等待业务区加载，再从顶部滚动到底；明确无权限时记录并跳过。禁止点击任何创建、发布、保存、上下架、退款、打款、提现、开通或关闭按钮。

## 页面记录

每页最少记录：中文菜单、稳定路径、页面标题、可见 Tab/筛选、指标口径、时间窗、当前实体、是否加载完整、是否有权限、可执行按钮类别和 nonClaims。
