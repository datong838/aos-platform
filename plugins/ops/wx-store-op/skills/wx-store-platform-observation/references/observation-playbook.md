# 微信小店观察规程

1. 用户先完成登录；不读取 Cookie、Token、Local Storage 或 Profile。
2. 先确认店铺名称，防止在错误经营实体上观察或操作。
3. 页面可能由微应用组件渲染，普通页面文本为空不等于页面无内容；需要以可见页面、内部业务区和截图相互核验。
4. 左侧菜单、页面主区和弹层可能独立滚动。鼠标先移入主内容区，再滚动到排行、来源、列表或分页末尾。
5. 慢页面至少等待一次稳定加载；先出现“0条”后又加载出数据时，旧值标 `LOADING_UNCERTAIN`，不得保留为事实。
6. 明确“暂无权限”立即记录 `PERMISSION_BLOCKED`，不继续等待，不解释为 0。
7. 列表总数、当前页样本和筛选条件分开记录；分页首屏不是全量。
8. 推荐、搜索、商品、人群等数据必须记录日期和对比周期。
9. 平台文案中的“平均提升”“可能获得推荐”属于产品说明，不是店铺效果。
10. 只读观察遇到验证码、登录失效、风控或店铺身份变化，立即停止并交还用户。
